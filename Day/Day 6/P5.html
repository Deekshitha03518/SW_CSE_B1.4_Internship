Display Property: Tells how an element behaves on a web page. It controlshow much space an element takes up and where it sits in realtion to surrounding elements. 4 types: Block: Takes full width Inline: Takes only as much width as necessary Inline-Block: Behaves like an inline element but can have a width and height None: Removes the element from the document flow
