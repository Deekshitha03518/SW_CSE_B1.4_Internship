CSS Units: are tye measurement units used to specify sizes,spacing & length related values in properties like width,height,nmargin etc. How big or small the elements are going to be.

1. Absolute Units: represent fixed values.They don't change based on parent element. parent element,screen size,font size. >>Pixels(px): 1px is considered as 1/96 of an inch >>Centimeters(cm),millimeters(mm),inches(in): Basis of real-world measurements >>Points (pt),picas(pc):lagacy approach when to use?: For print layout

2. Relative Units: are based on relation with another element's size, viewport size Responsive designs. a) Font-related units: >>em: relative to the font-size of the current elements's parent >>rem:root em: relative to the root element's(html) font size, not the parent >>ex: relative to the x-height b) Percentage based units: >>%(percent): relative to element's parent c) Viewport-realtive units: viewport: is the visible area of a web page in the browser window or on a device screen. The rectangukar area/region where browser rendors and shows content. >>vw:viewport width 1vw=1% of the viewport >>vh: Viewport height 1vw=1% of the viewport height >>vmin: 1vmin=1% of the smaller dimension (width or height) of the viewport >>vmax: 1vmax=1% of the larger dimension (width or height) of the viewport When to use which unit?: >>px: Fine or precise values >>rem: Font sizes or whenever spacing is needed, Responsive >>%: Great width and heights >>vw,vh,vmin,vmax: Ideal for full screen sections, it adapts to the screen size >>cm,mm,inch,pt: For print layout
